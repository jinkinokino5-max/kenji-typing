遊び方

はじめての方は、このページを上から読めば迷わず遊べます。 操作はキーボードだけで完結し、マウスは使いません。

ゲームの目的

KENJI TYPING は、宮沢賢治の作品を打ちながら読み進めるタイピングゲームです。 目的は二つあります。ひとつは日本語入力の速度と正確さを鍛えること、 もうひとつは一章を打ち終えたときに、作品を一篇読み通していることです。

画面には上段に原文、その下に打つべきひらがな、 さらに下にローマ字ガイドが並びます。原文は歴史的仮名遣いを含む原典どおりの表記、 ひらがなは音読したときの読みです。この二つを見比べながら打つことで、 文語の表記と実際の音の対応が自然に身につきます。

始めるまでの手順

  1. 日本語入力（かな漢字変換）を OFF にします。 Windows なら 半角/全角 キー、Mac なら 英数 キーです。 これを忘れると打鍵が変換に取られ、何を打っても反応しません。
  2. ゲームのページを開き、タイトル画面で何かキーを押します。
  3. 章えらびの画面になります。◀▶ で編（物語編・詩歌編・特別編）を、 ▲▼ で章を選び、Enter で決定します。
  4. 導入の文章が流れたあと、本編が始まります。

反応しないときは、まず日本語入力を疑ってください。 日本語入力が ON のままだと画面上部に警告の帯が出ます。 その場合は 半角/全角 キーなどで「半角英数」に切り替えてください。

操作方法

場面 キー はたらき
タイトル 任意のキー ホーム（章えらび）へ
章えらび ▲▼ 章を選ぶ
◀▶ 編を切り替える／メニュー項目を選ぶ
Enter 決定
プレイ中 英字キー ローマ字で入力する
Esc ひとやすみ（ポーズ）
ポーズ中 ▲▼ / Enter / Esc 「つづける」「この章を最初から」「章えらびへもどる」から選ぶ

入力にバックスペースはありません。打ち間違えるとその場でミスとして記録され、 画面がわずかに光って「✕ 打ったキー … つぎは 正しいキー」と表示されます。 間違えても止まらず、そのまま正しいキーを打てば先へ進みます。

ローマ字の打ち方は自由です

このゲームは特定のローマ字表記を強制しません。ふだんお使いの綴りがそのまま通ります。

  • し → shi / si / ci
  • ちょ → cho / tyo / cyo / chyo
  • じゃ → ja / jya / zya
  • 拗音は一括でも、分けても打てます。きょ → kyo / kilyo / kixyo
  • 促音は子音を重ねる形（kitte）のほか、ltu / xtu 単体も可
  • 撥音は nn / xn / n'。単独の n は、 直後が母音・な行・や行・「ん」・語末でないときだけ通ります （しんぶん の1つ目は n 可、げんいん の1つ目は nn が必要）

画面下のローマ字ガイドは、あなたが選んだ綴りに追従します。 zi と打ち始めればガイドも zi の並びに切り替わるので、 途中で表示と食い違って混乱することはありません。

賢治の作品特有の旧かな（ゐ・おまへ・さう など）の打ち方は、 打ち方のコツで詳しく説明しています。

スコアの仕組み

1問ごとのスコア

問題を打ち終えるたびに、次の要素からスコアが決まります。

  • 文字数：かな1文字につき10点が基礎点になります。長い問題ほど高得点です。
  • 速度：想定される標準の所要時間（毎秒4.5打で打った場合）と、 実際にかかった時間の比で 0.5〜2.5 倍されます。
  • 正確さ：ミスが多いほど倍率が下がり、さらにミス1回につき20点が引かれます。

章ごとのボーナス

  • 完璧クリア（ミス0）：+5,000点
  • ノーミス達成：+2,000点
  • 速度S評価（平均速度倍率1.5以上）：+1,000点

ランク

ランク 合計スコア
S9,000 以上
A7,000 以上
B5,000 以上
C3,000 以上
D1,000 以上
E1,000 未満

ミス1回のペナルティ（20点＋倍率低下）に対し、ノーミス達成のボーナスは2,000点です。 速く打つよりも、ミスをしないほうが圧倒的に得点が伸びます。 S ランクを狙うなら、まず一度もミスせず打ち切ることを目標にしてください。

コンボ

かなを1文字打ち終えるごとにコンボが1つ増え、ミスすると0に戻ります。 コンボが伸びるほど背景の情景が高まり、BGM も厚みを増します。 コンボ自体は得点に直接加算されませんが、達成した最大コンボは記録に残ります。

記録とレベル

  • 章ごとの最高スコア・ランク・読了率が保存されます。
  • 累計の打鍵数1,000打ごとにレベルが1つ上がります。
  • ミスの多かったキーが「苦手キー」として集計されます。
  • ミス0でクリアすると、章ごとの専用バッジが手に入ります。

これらはすべてお使いのブラウザの中だけに保存されます。 サーバーへは送られないため、別の端末やブラウザでは引き継がれません。 詳しくはプライバシーポリシーをご覧ください。

設定でできること

ホーム画面の「せってい」から、次の項目を切り替えられます。

項目 内容
ローマ字ガイド 次に打つローマ字を問題文の下に表示するかどうか。OFF にすると難度が上がります。
速度・正確率 プレイ中に「打/秒」と「正確率」を表示します。
見やすさ優先 背景を暗く落とし、文字をはっきりさせます。目が疲れるときに。
おと（BGM・SE） 音楽と効果音の ON / OFF。
苦手キーの記録 これまでのミス記録を消去します。

ホームにはほかに「きろく」（成績の一覧）、「あそびかた」（ゲーム内の簡易説明）、 「ごいけん」（ご意見の送り先）があります。

推奨環境

  • パソコン（Windows / macOS / Linux）と物理キーボード
  • Google Chrome / Microsoft Edge / Firefox / Safari の最新版
  • 日本語入力（かな漢字変換）は OFF

スマートフォンでは遊べません。 ローマ字を1キーずつ打つ設計のため、画面キーボードでは成立しないからです。 外付けキーボードをつないだタブレットであれば、注意画面のボタンから開始できます。
