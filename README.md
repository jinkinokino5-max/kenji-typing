# KENJI TYPING

宮沢賢治の言葉を、一文字ずつ打つタイピングゲームです。
物語・詩・オノマトペを打ちながら読み、打ち終えたときには一篇を読み通している——
そんな読書体験を目指してつくりました。

ブラウザだけで動きます（インストール不要・保存はブラウザ内のみ）。

## あそびかた

1. ローマ字入力で、画面のひらがなを打ちます（りんご → `ringo`）。
2. 打ち方は自由です。`し` は `shi` / `si` / `ci`、`ちょ` は `cho` / `tyo` / `cyo` のいずれでも通ります。
3. 旧かなづかいも、字義どおり・口語読みの両方を受け付けます（`ゐる` は `wiru` でも `iru` でも可）。
4. `Esc` でひとやすみできます。

**日本語入力（かな漢字変換）は OFF にしてください。** ON のままだと打鍵が変換に取られて反応しません。
ゲーム側でも検知して画面に警告を出します。

物理キーボードが必要です。スマートフォンでは遊べません。

## 収録内容

| 編 | 章数 | 内容 |
| --- | --- | --- |
| 物語編 | 5 | よだかの星／グスコーブドリの伝記／ざしき童子のはなし／オツベルと象／銀河鉄道の夜 |
| 詩歌編 | 15 | 永訣の朝／雨ニモマケズ／春と修羅（序）／青森挽歌／恋と病熱 ほか |
| 特別編 | 4 | 賢治のオノマトペを、ジャンル別に一文まるごと |

物語編は原文から重要な一節を抜き出し、詩歌編は原則として全文を収録しています
（きわめて長い詩は、冒頭と結びを残して中盤を省略し、その旨をデータに明記しています）。

## 本文の出典と権利について

- 本文はすべて **宮沢賢治（1896–1933）** の作品です。著作権の保護期間は満了しており、
  パブリックドメインとして自由に利用できます。
- 底本は [青空文庫](https://www.aozora.gr.jp/index_pages/person81.html) の公開テキストです。
- 表示用の本文（`text`）は原典の表記を保ち、歴史的仮名遣いもそのまま残しています。
  打鍵対象の読み（`kana`）は、音読したときの発音にもとづくひらがなです。
- 抜粋・省略を行った箇所は、各データファイル（`src/data/*.ts`）のコメントに記しています。

## 開発

```bash
npm install
npm run dev        # 開発サーバ
npm run build      # 型チェック＋本番ビルド
npm test           # 打鍵判定・画面レイアウト・通しプレイの自動検証
```

`npm test` は実ブラウザを使わず、描画呼び出しを記録するモックへ各画面を描かせて
「画面からはみ出していないか」「全問題文が最後まで打ち切れるか」を検査します。

## 感想・ふしぎな挙動の報告

ゲーム内の「ごいけん」からフォームを開けます。
送り先は `src/config.ts` の `FEEDBACK_FORM_URL` に設定します（未設定のあいだは「準備中」と表示されます）。
